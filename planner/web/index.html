Course path planner

Upload a course CAD file, place start, checkpoints and goal, plan with gcopter_planner. Map frame: metres, z up.

1 · Course

2 · Mission

Pick a mode, then click in the view. The start goes on the ground (the pad), checkpoints at Click height, the goal at Goal height above the ground.
The path starts at rest Start height above the pad (the flight code takes off to it) and ends at rest Goal height above the landing spot (the flight code lands from there).
Heading is the drone's yaw on the pad, CCW from map +x (the arrow).

3 · Plan

Vehicle radius + safety margin. The planner inflates every surface (floor included) by this, rounded up to whole voxels: . It keeps the path out of that zone where it can; time inside is reported, not refused. Playback shows the radius as a sphere around the drone, red when inside.
