Top view: forward is up, right is right, 0.5 m grid, origin on the pad. Drag a blue handle to move the path sideways; drag on the height strip to move it up or down. Nearby points follow with a smooth falloff set by the smoothing width (seconds of path). Timing is kept; velocity and acceleration are recomputed; yaw is kept as planned. Scroll to zoom, drag empty space to pan.

Grey = original, green = edited. Export writes the same 12 columns (PX4 NED at the pad), ready for import_path.py.
