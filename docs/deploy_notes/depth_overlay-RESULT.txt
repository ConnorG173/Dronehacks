Depth Anything fence overlay — deployed 2026-11-08 01:01 UTC

The live USB dashboard displays teal estimated surface cells on the existing
top-down fence map. Show depth defaults on. Cells share the map's PX4-local ENU
coordinates and home rotation. Original flight controls are unchanged.

Source: existing Depth Anything V2 Small relative TensorRT FP16 engine,
claude/models/da2s_252x406_fp16.engine. Each image gets a fresh inverse-depth
metric fit against synchronized stereo; a failed fit is never reused.
Rectified optical rays use live camera calibration/TF and image-aligned USB
position/attitude. Pose matching uses host receipt timestamps, not FC boot time.
Processing is capped at 2 Hz, with one CPU thread per numeric library and nice 10.

Display retains vertical surface cells in 8 cm world bins, optical depth
0.3–4 m, gravity-level height -0.25 to +0.8 m relative to the body. Each bin
needs two returns spanning 0.12 m vertically. Flat floors are suppressed.
This is estimated surface visualization, not a complete obstacle/free-space map.
It does not steer the vehicle or establish clearance. Empty cells are unknown.
Stale/invalid/unscaled frames disappear; live image age must be <=1.5 seconds.

Startup: USB dashboard.launch.py launches a stdlib-only ground gate first.
Imports/model loading wait for fresh disarmed/landed USB telemetry, stable for
two seconds; the worker also checks fresh ROS ground state before model load.
The worker respawns independently after ten seconds. Its exit does not stop
flight nodes. Existing enabled skybeta-stack.service and USB wrapper select it
on boot. Boot configuration was checked; no reboot was performed for this change.

Validation: 33 dashboard readiness/motion/cache tests, 8 geometry tests, 2 stereo
pairing tests, 6 ground-gate tests, and 9 browser-JavaScript tests passed.
Served HTML and authenticated read-only API both verified after deployment.
No verification command armed or moved the drone. Deployment happened while
fresh independent USB and DDS observations confirmed disarmed and landed.
